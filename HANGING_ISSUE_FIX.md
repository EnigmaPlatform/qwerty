# Исправление проблемы с зависанием при генерации ответов

## Проблема
Программа зависала после отправки вопроса, что было связано с отсутствием ограничений времени и неподходящими параметрами генерации для T5 модели.

## Внесенные изменения

### 1. Добавлен таймаут для генерации ответа
- Использован декоратор `@timeout_decorator.timeout(30, use_signals=False)` для метода `_generate_with_neural_model`
- Добавлена обработка исключения `timeout_decorator.TimeoutError` в методе `generate_response`
- При превышении 30-секундного таймаута возвращается вежливое сообщение пользователю

### 2. Улучшены параметры генерации
- Добавлен параметр `max_new_tokens=256` для предотвращения бесконечной генерации
- Добавлен параметр `num_return_sequences=1` для получения одного ответа
- Добавлен параметр `repetition_penalty=1.2` для предотвращения зацикливания
- Улучшена логика определения `min_length`, чтобы гарантировать `min_length < max_length`

### 3. Улучшена обработка T5 модели
- Исправлена логика обработки префиксов для T5 моделей
- Добавлена дополнительная очистка ответа от префикса "summarize:" при необходимости
- Использован правильный `decoder_start_token_id` для T5 моделей

### 4. Улучшена обработка исключений
- Добавлена обработка таймаутов и других исключений в методе `generate_response`
- При ошибках возвращается осмысленное сообщение пользователю

## Результат
- Программа больше не зависает при генерации ответов
- Установлены разумные ограничения по времени и количеству генерируемых токенов
- Сохранена совместимость с T5 моделями
- Улучшена стабильность работы системы
